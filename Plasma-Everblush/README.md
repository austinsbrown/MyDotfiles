# Everblush for KDE Plasma 6

A Plasma 6 port of the Everblush XFCE rice from
[Miserable_Xfce](https://github.com/mehedirm6244/Miserable_Xfce) (branch `Everblush`).
The palette was taken from that branch's Xresources, kitty, GTK, xfwm4 and Kvantum configs.
See [PALETTE.md](PALETTE.md) for the full table.

## Contents

| Path | What it is | Installs to |
|------|------------|-------------|
| `color-schemes/Everblush.colors` | Plasma color scheme | `~/.local/share/color-schemes/` |
| `konsole/Everblush.colorscheme` | Konsole terminal colors | `~/.local/share/konsole/` |
| `plasma/desktoptheme/Everblush/` | Plasma Style for the panel, popups and widgets | `~/.local/share/plasma/desktoptheme/` |
| `aurorae/themes/Everblush/` | Window decoration, a port of the xfwm4 theme | `~/.local/share/aurorae/themes/` |
| `icons/generate-glyphs.py` | Builds Everblush-glyphs, an overlay on Tela with palette-colored tray and Dolphin glyphs | `~/.local/share/icons/Everblush-glyphs/` |

## Install

```bash
./install.sh           # copy files into ~/.local/share
./install.sh --apply   # copy and apply them to the running Plasma session
```

To apply manually, open System Settings and pick Everblush under each page:

- **Colors & Themes > Colors**
- **Colors & Themes > Plasma Style**
- **Colors & Themes > Icons**, pick Everblush-glyphs (needs Tela installed in `~/.local/share/icons`)
- **Colors & Themes > Window Decorations**. Under "Configure Titlebar Buttons", put minimize, maximize and close on the right to match xfwm.
- **Konsole > Settings > Edit Current Profile > Appearance**

## Regenerating

The SVG-based pieces are generated by scripts, so tweak the constants and re-run them instead of hand-editing SVGs:

- `plasma/generate-desktoptheme.py` rebuilds the Plasma Style. `plasma/check-ids.py` compares its element IDs against Breeze.
- `icons/generate-glyphs.py` rebuilds Everblush-glyphs from Tela. Edit its `RULES` table to change which icons get which color. Most colors are ColorScheme classes, so they follow the color scheme; blue, magenta and cyan are hard-coded.
- `aurorae/generate.py` rebuilds the window decoration. Keep its shadow sizes in step with the Padding values in `Everblushrc`.

## Matching the rest of the XFCE setup

- **Fonts:** Roboto for the UI, JetBrainsMono Nerd Font for monospace.
- **Cursor:** Qogir, from the original repo's `Dotfiles/.local/share/icons/Qogir-Cursor`.
- **Qt apps:** the Kvantum theme in the original repo still works on Plasma. Select it in Kvantum Manager and set the Application Style to kvantum.
- **Panel:** the XFCE panel was a 44px bar along the bottom of the screen.
